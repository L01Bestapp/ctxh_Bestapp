# UniVolunteer (CTXH BestApp)

UniVolunteer is a comprehensive mobile platform designed to bridge the gap between university students and volunteer organizations. It streamlines the process of organizing, finding, and participating in social work and community service activities.

## 🚀 Project Overview

The application facilitates a seamless ecosystem for:
*   **Students:** To discover meaningful volunteer opportunities, track their social work days (CTXH), and manage their engagement history.
*   **Organizations:** To recruit volunteers, manage activity schedules, and automate attendance tracking via QR codes.
*   **Administrators:** To oversee the platform, verify organizations, and ensure community safety.

## ✨ Key Features

### 🎓 For Students
*   **Activity Discovery:** Browse upcoming events with advanced filters (Education, Environment, Social Support, etc.).
*   **Easy Registration:** One-tap enrollment for activities.
*   **Attendance Tracking:** Personal Dynamic QR Code for quick Check-in/Check-out at events.
*   **Progress Monitoring:** Track total CTXH days and view participation history.
*   **Notifications:** Real-time updates on activity status and schedules.

### 🏢 For Organizations
*   **Activity Management:** Create, update, and manage volunteer events.
*   **Volunteer Management:** Review student profiles and Approve/Reject enrollment requests.
*   **Smart Attendance:** Built-in QR Code Scanner to instantly check students in and out of events.
*   **Dashboard:** specialized view for tracking organization's activities.

### 🛡️ Core Technology
*   **Frontend:** React Native with Expo (TypeScript).
*   **Backend:** Java Spring Boot (implied).
*   **Deployment:** Android (APK) & iOS.

## 📂 Project Structure

*   `frontend/`: The main React Native mobile application source code.

## 🛠️ Getting Started

To run the mobile application:

1.  Navigate to the **frontend** directory:
    ```bash
    cd frontend
    ```
2.  Follow the instructions in `frontend/README.md` to install dependencies and start the server.
